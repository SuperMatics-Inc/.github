# SuperMatics

**AI for superconductors.** SuperMatics, Inc. is a Berkeley, California company
building the intelligence, data, and IP layer for superconducting materials.

Our models predict superconducting properties, write the synthesis recipe, and
simulate the finished wire or device. Candidates are made and measured with
research partners, and every result, failures included, retrains the models.
